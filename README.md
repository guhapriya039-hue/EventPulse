# EventPulse

**EventPulse – Smart Event Experience platform for intelligent navigation, crowd-aware routing, accessibility, safety, and real-time event updates.**

EventPulse is a TypeScript-based platform to improve event navigation and attendee experience using crowd-aware routing, accessibility-first design, and real-time updates.

## Features

- Intelligent navigation and routing for event attendees
- Crowd-aware pathfinding to reduce congestion and improve flow
- Accessibility-focused routing and UI considerations
- Real-time event updates and notifications
- Safety features and alerts for attendees and staff
